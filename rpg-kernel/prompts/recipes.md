# 剧情配方库（只给「规划」步骤用；改完即生效）
# 出处：用户《长线剧情、虚构人物与档案馆总设计书》第四节。这是剧情的结构，不是历史事实。

【十二个剧情原子：对手想要什么 / 隐藏信息 / 反转点】
求人：对方要主角出手，不说真实目的 / 求人者另有所图 / 帮完才发现是为了牵制第三方
被求：主角有求于人，对方要价 / 对方也需要主角，只是不说 / 主角发现可以反过来讲条件
谈判：各有底线，互相试探 / 一方底线其实更低 / 谈判桌外有人在改变局面
揭秘：某个秘密被揭开 / 只揭开一半 / 揭秘者本身是秘密的一部分
背叛：自认为忠诚的人转向 / 他有不得已或被人许诺 / 背叛其实是对方设的局
误会：双方各自理解错了 / 传话人改了意思 / 误会被某方将错就错利用
选边：两方都要主角站队 / 两方都不真心信他 / 第三种选择出现
立威：主角要让人服 / 有人故意挑衅试探 / 立威的方式本身带来新敌人
示弱：主角暂时服软 / 对手把示弱当真 / 示弱正是诱敌
借势：借别人的力量做事 / 借势有代价，对方也在借他 / 势的主人先倒了
报恩：有人来还旧恩 / 他的「恩」其实是债 / 报恩的方式添了大麻烦
清算：旧账被翻出来 / 翻账的人手里有证据 / 证据是伪造的，或证明了别的事

【十个配方（多回合骨架，写进计划卡的 recipe_beat 时注明第几拍）】
请君入瓮：对手示好条件优厚 → 好处太好、查动机 → 查出陷阱 → 反设局/将计就计/揭穿/装不知 → 结果由选择与准备共同决定
借刀杀人：想除一人不能亲自动手 → 找到有仇的第三方 → 递消息证据机会不留痕 → 第三方动手但超出预期 → 欠人情或养出新威胁
功高震主：立了大功众人祝贺 → 上头态度微妙 → 有人劝急流勇退或拥兵自保 → 自削/外放/上表/扩权 → 权位与人际重排
继承之争：要人病重或去世继承未定 → 各方推人主角是关键一票 → 候选人分别来开条件 → 站队或折中 → 落选者成潜在对手
养寇自重：本应剿灭的敌人对自己有用 → 留着并控制规模 → 有人发现并要挟 → 对手做大失控 → 亲自收拾、代价更高
科场与举荐：门生亲信要出路名额有限 → 几方都要塞人 → 有人以人情把柄施压 → 举荐谁并担连带 → 被荐者日后所为成得失
漕运与贪腐：钱粮账对不上 → 牵涉上司同僚大户 → 调查被阻、有人送好处 → 查到底/压下去/借此要价/移交 → 官场位置改变
灾荒中的政治：灾情上报与实际有差 → 官仓大户官府各有算盘 → 流民、治安、疫病 → 救人/保位/不得罪大户 → 人心名声成资本或包袱
后院起火：在外忙大事家里出事 → 家务被政敌利用 → 只能先顾一头 → 家中某人做了意想不到的事 → 家庭成新变量
使者来了：使者带条件来 → 身份礼数随员都在传信号 → 看似合理暗藏要害的条件 → 内部意见分裂 → 答复决定对方下一步

【日常回合的小戏（每个都要带一个小钩子）】
宴饮—席上有人说了一句只有你听懂的话｜赶集—摊上有件本不该出现在此的东西｜迎送—送行人里有张不该在场的脸｜祭祀—祭文里一个名字被悄悄改过｜探病—病人说了句似乎神志不清的话｜查账—一个数字总差一点点｜点卯—有人替别人点了名｜断小案—撒谎的一方理由令人同情｜拜访乡老—提到几十年前的旧事｜过节—节礼里夹了一封信｜博戏—对手故意输给你｜书信—来信字迹与以往不同｜犒军—队列里少了一个人｜修缮—工匠挖出了一样东西｜讲学—学生问得太深｜驿站—有人在等你但不说是谁

【反转三件套】先放一个不起眼的预示，再放一个把玩家引向错误解释的误导，最后揭示。常用反转：示好者才是对手；看似敌人其实在保护你；你追查的真相早被人知道并利用你的调查；意外是设局；信任的人另有身份；证据是对手故意留的；以为化解的危机只是换了形式；两个死敌在暗中合作；你的善举成了把柄。

【抉择类型（每三到五轮一个中抉择，检查别总是同一类）】忠与义、利与名、亲与国、速与稳、狠与仁、公与私、明与暗。好抉择：两边都想要，各有可见代价，没有标准答案，选完世界有可见变化。
